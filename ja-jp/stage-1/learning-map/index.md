# アイデアからAIプロダクトへ

::: info 特別協力
本コースのテスト、フィードバック、改善にご協力くださった **清華大学深圳国際大学院** の学生の皆さんに、心より感謝いたします。皆さんの意見と貢献のおかげで、このコースはより実践的で学びやすいものになりました。[👉 コントリビューター一覧を見る](https://github.com/datawhalechina/easy-vibe#-contributing--contributors)
:::

かつてソフトウェアを作るには、高いハードルがありました。プログラミングを理解し、アルゴリズムを学び、さらに何年ものプロジェクト経験が必要でした。

しかし今は違います。アイデアさえあれば、AIがコードを書くところから手伝ってくれます。

これは非常に大きな変化です。**プログラミング言語は、自然言語へと近づいています。**

大規模言語モデル（LLM）の登場により、開発はもはや「一部の技術者だけのもの」ではなく、誰もが使える道具になりつつあります。以前もっとも難しかったのは「どうコードを書くか」でした。今もっとも重要なのは、「**何を作りたいのか**」を明確にすることです。

> **Vibe Codingとは？**
> 簡単に言えば、「話すようにプログラミングする」ことです。コードを直接書く代わりに、AIと対話しながら、要件整理、実装、修正、改善を進めていく開発スタイルを指します。

もちろん、AIにコードを書かせることは最初の一歩にすぎません。本当に使えるプロダクトを作るには、次のような課題に向き合う必要があります。

- AIに、読みやすく保守しやすいコードを書かせるにはどうすればよいか？
- 断片的なコードを、実際に動くアプリケーションへ組み上げるにはどうすればよいか？
- 作ったアプリを公開し、実際のユーザーに使ってもらうにはどうすればよいか？
- テキスト生成、画像認識、音声処理などのAI機能を、自分のプロダクトにどう組み込めばよいか？

このコースでは、こうした問いへの答えを、実際に手を動かしながら学んでいきます。

学生、教師、医師、工場や現場で働く人、あるいはこれまで技術にほとんど触れてこなかった人でも大丈夫です。何年もプログラミングを勉強してから始める必要はありません。2週間あれば、動かせて、人に見せられるプロダクトのプロトタイプを作れるようになります。

| あなたの立場 | このコースで得られること |
|---------|-------------|
| 学生 | 課題、コンテスト、起業アイデアを、自分の手で形にできるようになります |
| 社会人 | 繰り返し作業を自動化し、仕事の効率を高め、場合によっては副業の土台も作れます |
| プロダクトマネージャー / デザイナー | 紙やスライド上のアイデアを、上司や顧客に見せられる動くデモへ変えられます |
| 起業家 / 中小企業の経営者 | 高額な外注に頼らず、低コストでアイデアを検証し、MVPを作れます |
| 教師 / 教育関係者 | 教材、授業支援ツール、自動出題ツールなどを作り、教育の効率を高められます |
| 医師 / 弁護士 / 専門職 | 専門業務の一部を自動化し、自分専用の効率化ツールを作れます |
| すべての人 | AIを使って、生活や仕事の具体的な困りごとを解決できます |

AI時代においては、技術そのものよりも、アイデアと実行力の価値がますます高まっています。

この学習パスを進めることで、次の力が身につきます。

- **Vibe Codingによる開発力：** Vibe Codingの考え方とAIコーディングツールを使いこなし、開発効率を大きく高めます。構文を丸暗記するのではなく、AIを導いて高品質なコードを生成する方法を学びます。
- **フルスタック開発スキル：** UI設計からフロントエンド実装、データベース設計からAPI開発、ローカル開発からクラウドへのデプロイまで、現代的なWebアプリケーション開発の全体像を身につけます。
- **AI機能の組み込み力：** さまざまなマルチモーダルAI APIを利用し、テキスト、画像、音声などのAI機能をアプリケーションへ自然に組み込みます。さらにRAGなどの技術を使い、より賢いプロダクトを構築します。
- **プロダクト思考と運用力：** ユーザーリサーチ、要件分解、MVP設計、プロダクト改善、決済連携、ユーザー管理まで、プロダクト開発と運用の一連の流れを理解します。

# 学び終えると何ができるようになるのか？

## 第1段階：最初のプロダクトプロトタイプを作る

この段階は、プログラミング経験がまったくない人、あるいは少し触れたことはあるものの自信がない人に向いています。最初から大量の理論を学ぶのではなく、実際に作りながら、AIツールを使ってコードを書く感覚を身につけます。

**学び終えると、次のことができるようになります。**

- AIプログラミングツールを使って、Webアプリケーションを自力で作る
- プロダクトのアイデアを、クリックや操作ができるプロトタイプに変える
- プロトタイプにAI機能（例：テキストから画像生成、AIチャットなど）を追加する
- エラーが出たときに、原因を調べて解決する流れを理解する

簡単に言えば、「実際に動き、人に見せられるもの」を作れるようになります。

まずは小さなゲームを通じてAIプログラミングを体験します。その後、AIプログラミングツールを使ってコードを書き、エラーを直す方法を学びます。シンプルなページから始め、少しずつ複数ページのアプリケーションへ発展させ、画像生成やAIチャットなどの機能を加えていきます。最後には、ひとつの完成したプロジェクトを自力で作り上げ、自分のアイデアを現実の形にできるようになります。

# なぜプロジェクト形式で学ぶのか？

> **現実世界の課題**
>
> 理由はとてもシンプルです。今の状態のまま現場に入ると、実際のプロジェクトや上司・顧客からの要求に直面したとき、前に進めなくなる可能性があります。現実の仕事では、次のような状況がよく起こります。

> メンター / 上司：「xxxを作ってください。目標はyyyの効果を出すことです。」
>
> 詳細なドキュメントは？既存のフレームワークは？明確な要件定義書は？──多くの場合、最初から揃っているわけではありません。

実際の仕事の多くは、不確実性の高い環境で、見たことのない問題を解くことです。要件は曖昧で、境界は変わり、誰かが標準解答を教えてくれるわけではありません。自分で調べ、試し、プロトタイプを作り、何度も改善しながら、最終的に「動く・使える・公開できる」解決策を出す必要があります。

このコースが目指しているのは、比較的安全な学習環境の中で、現実の開発に近い体験を先にしてもらうことです。

- 少し難しそうに見えるプロジェクト課題を通じて、問題を分解し、設計し、自分で資料を探す練習をする
- 便利すぎるテンプレートに頼り切るのではなく、ある程度規模のあるコードベースを読み、理解し、改造する力を身につける
- アイデアから公開までの流れを通じて、プロダクトを0から1へ立ち上げる一連のプロセスを体験する

短期的には、この学び方は少し大変に感じるかもしれません。しかし長期的には、就職やキャリア形成における大きな強みになります。問題に向き合う粘り強さ、不確実な状況で突破口を見つける力、AIを単なるデモではなく実際に使えるプロダクトへ落とし込む力が身につきます。

# 質問の技術：AI時代の必須スキル

AI時代において、質問する力は基本スキルのひとつです。同じコード、同じエラーであっても、**どのように質問するかによって、AIが返す答えの質は大きく変わります**。曖昧な一般論で終わることもあれば、すぐに実行できる具体的な修正案が返ってくることもあります。

**良い習慣をつけましょう。** 「AIに質問すること」を日常の開発フローに組み込み、分からないことや詰まったことがあれば、早めに相談するようにします。

## なぜ必須スキルなのか？

- **現実には、完璧なドキュメントはほとんどありません。** 不明確な要件、途中まで作られたコード、断片的なエラー情報に向き合うことが多くあります。
- **AIは、いつでも近くにいるメンター兼同僚です。** 質問が上手くなるほど、AIを質の高いペアプログラミング相手として使えるようになります。
- **成果の上限は、コミュニケーションで変わります。** 重要な情報を渡し、出力形式や条件を明確にするほど、回答は実用的になります。

**よくある失敗例：** 「なぜエラーが出るの？」とだけ聞いても、AIは推測を並べるしかありません。必要な文脈をそろえて伝えることで、初めて実行可能な解決策が得られます。

## 情報をAIに渡す方法：スクリーンショット vs コピー＆ペースト

どちらの方法も使えますが、向いている場面が異なります。

| 方法 | 向いている場面 | 重要なポイント |
| ------------ | ----------------------------------------- | ----------------------------------------- |
| **コピー＆ペースト** | エラースタック、ログ、コード、設定、APIレスポンス | できるだけ全体を貼る。キーワード1行だけを切り取らない |
| **スクリーンショット** | UIレイアウトの崩れ、操作の異常、ツール画面でボタンが見つからない場合 | 画面全体を写し、重要な場所に印を付ける。できれば一言説明を添える |

::: danger ⚠️ 重要な前提
**すべてのAIが画像入力に対応しているわけではありません。** スクリーンショットを使って相談するには、AI側に画像を理解・分析できるマルチモーダル能力が必要です。現在、画像入力に対応している代表的なAIには、Claude（Anthropic）、GPT-4V / GPT-4o（OpenAI）、Gemini（Google）、通義千問、文心一言などがあります。

**使っているAIが画像入力に対応していない場合**、スクリーンショットは認識されません。その場合は、テキストをコピー＆ペーストして相談してください。
:::

## AIに「よく分かる説明」をしてもらうためのプロンプト

答えだけでなく、理解そのものを深めたい場合は、次のような指示を使うと説明の質が上がります。

> **学習型の質問例**
>
> - 「まず5文でこの概念を説明してください。そのあと、私の理解を確認するための質問をいくつか出してください。」
> - 「このエラーメッセージを詳しく説明してください。なぜこのエラーが出るのか理解したいです。」

# 何度やっても解決できず、諦めたくなったら

もしかすると、努力の方向が少しずれているだけかもしれません。一人で抱え込まず、作者やティーチングアシスタントに相談してみてください。これまで試したこと、具体的に詰まっている場所、そして今の気持ちを正直に共有しましょう。多くの場合、方向を少し変えたり、必要な知識をひとつ補ったりするだけで、再び前に進めるようになります。
